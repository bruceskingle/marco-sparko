# Account

The details of the Octopus user the API key belongs to. A user can have more than one account, e.g. one for an old
property, and the app shows one at a time: if there is more than one, choose which in the **Account** row. Every
Octopus page, bills, properties, meters, electricity and EV charging, then shows that account, and the choice is saved
with the profile. Until one is chosen, the app uses the first account Octopus lists.
